# Security Policy

## Reporting a Vulnerability

If you discover a security or data-integrity vulnerability in Vantage V-AI (such as frame-parsing issues, unbounded allocation bugs, or checksum bypasses), please report it responsibly:

1. **Do not** open a public GitHub issue with exploit details before a fix is available.
2. Open a private GitHub Security Advisory on `khoadev-vn/VANTAGE-V-AI` or contact the maintainer directly.
3. Include a minimal reproducible script, Python version, OS, and expected vs. actual behavior.
